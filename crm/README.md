# CRM کاروان صنعت

برنامه‌ی جدا (دیتابیس جدا) برای فروش: ثبت سریع درخواست با گوشی، ۶ مرحله، پیگیری با یادآور صبحگاهی بله،
تاریخچه‌ی هر مشتری، مشتری‌های فصلی، گزارش تبدیل به تفکیک منبع/کد آگهی/دسته.

اجرا: `python -m crm.server` (پورت `PORT`، پیش‌فرض 10001). صفحه: `/`، سلامت: `/health`.

## متغیرها (Coolify — فقط صاحب فروشگاه وارد می‌کند)
| متغیر | توضیح |
|---|---|
| `CRM_DATABASE_URL` | Postgres جدا (crm-db) |
| `CRM_SECRET` | حداقل ۳۲ حرف تصادفی (امضای ورود) |
| `CRM_ADMIN_USER`، `CRM_ADMIN_PASSWORD` | اولین کاربر؛ فقط وقتی هنوز کاربری نیست |
| `CRM_STATS_TOKEN` | همان مقدار در پنل بازاریابی؛ پنل فقط عدد می‌گیرد (`GET /api/stats`) |
| `BALE_BOT_TOKEN` | ربات بله برای یادآور ساعت ۸:۳۰ |
| `CRM_PUBLIC_URL` | `https://crm.caravansanat.com` (لینک داخل یادآور) |

در پنل بازاریابی: `CRM_URL=https://crm.caravansanat.com` و همان `CRM_STATS_TOKEN`.

## حریم خصوصی
نام و شماره‌ی مشتری فقط در دیتابیس CRM است. پنل بازاریابی فقط «تعداد درخواست/خرید/فروش» به تفکیک کد آگهی و منبع را می‌خواند.
