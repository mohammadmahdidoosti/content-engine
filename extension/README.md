# جمع‌آور کاروان صنعت (افزونه‌ی کروم)

کارهایی که به آی‌پی ایران یا حساب‌های وارد‌شده‌ی صاحب فروشگاه نیاز دارند، بدون دخالت Claude:
ایتا (جست‌وجوی سراسری و بازدید پست‌ها)، تلگرام (جست‌وجوی کانال)، ترب (قیمت و پنل فروشنده)، گوگل.

نصب: Chrome → `chrome://extensions` → Developer mode → Load unpacked → همین پوشه.
تنظیم: آیکن افزونه → آدرس پنل و «توکن جمع‌آور» (همان `COLLECTOR_TOKEN` که در Coolify گذاشته‌اید) → ذخیره → آزمایش اتصال.

توکن جمع‌آور فقط به سه مسیر دسترسی دارد: `GET /api/collector/tasks`، `POST /api/ext/import`، `POST /api/collector/status`.
