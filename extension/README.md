# جمع‌آور کاروان صنعت (افزونه‌ی کروم)

کارهایی که به آی‌پی ایران یا حساب‌های وارد‌شده‌ی صاحب فروشگاه نیاز دارند، بدون دخالت Claude:
ایتا (جست‌وجوی سراسری و بازدید پست‌ها)، تلگرام (جست‌وجوی کانال)، ترب (قیمت و پنل فروشنده)، گوگل.

نصب: Chrome → `chrome://extensions` → Developer mode → Load unpacked → همین پوشه.
تنظیم: آیکن افزونه → آدرس پنل و «توکن جمع‌آور» (همان `COLLECTOR_TOKEN` که در Coolify گذاشته‌اید) → ذخیره → آزمایش اتصال.

توکن جمع‌آور فقط به سه مسیر دسترسی دارد: `GET /api/collector/tasks`، `POST /api/ext/import`، `POST /api/collector/status`.

## بررسی قیمت محصولات سایت (نسخه‌ی 1.4.0)
کار «ترب: بررسی قیمت محصولات سایت» محصولات منتشرشده را از کراولر می‌گیرد (`GET /api/torob/next`) و نتیجه را به کراولر برمی‌گرداند (`POST /api/torob/result`).
ساعتی حداکثر ۱۵ کالا، بین هر دو کالا ۱ تا ۲.۵ دقیقه؛ سقف روزانه را کراولر نگه می‌دارد. کلید: `crawler.caravansanat.com/api/torob/token`.
کار قدیمی «مقایسه‌ی قیمت کالاهای کمپین» هم آهسته‌تر شد (۳۰ تا ۶۰ ثانیه بین کالاها).

## نسخه‌ی 1.4.1 (نسخه‌ی مشترک)
از این نسخه، یک افزونه برای هر دو پروژه است: پنل بازاریابی (content-engine) و کراولر (بررسی قیمت محصولات سایت).
تغییر نسبت به 1.4.0: اگر تب ایتا/تلگرام به پنجره‌ی دیگری برده شود، آخر کار درست بسته می‌شود.
